# Game Blueprint

Game Name: SkyDock
Genre: Arcade Platformer
Orientation: Landscape
Platform: Mobile Web

## Mechanics
- Player jump and double jump
- Climb ladder
- Enemy patrol (3 types)
- Collect coins and items
- Level progression (5 levels)
- Score multiplier
- Lives system (3 lives)

## Art Style
Retro pixel, 16-bit style

## Difficulty
Increasing each level - more enemies, faster speed

## Special Features
- Mobile touch controls (left, right, jump buttons)
- Sound effects
- High score system (localStorage)
- Game over and win screen
